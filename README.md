# Carbon Footprint Predictor

## Features
- Predict carbon footprint using Linear Regression
- Classify emission level using Logistic Regression
- Personalized eco-friendly recommendations using Google Gemini AI
- Modern Flask + HTML/CSS/JS interface

## Technologies
- Python
- Flask
- Scikit-learn
- Pandas
- HTML
- CSS
- JavaScript
- Google Gemini API

## Installation

pip install -r requirements.txt

Create a .env file:

GEMINI_API_KEY=YOUR_API_KEY

Run:

python app.py
